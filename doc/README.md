# Documentation

Folder for storing all documents associated with the package.

## Setting up udev permissions
```
sudo groupadd plugdev
sudo usermod -a -G plugdev $USER
sudo touch /etc/udev/rules.d/99-crazyradio.rules
```

Add to the `/etc/udev/rules.d/99-crazyradio.rules` file:
```
# Crazyradio (normal operation)
SUBSYSTEM=="usb", ATTRS{idVendor}=="1915", ATTRS{idProduct}=="7777", MODE="0664", GROUP="plugdev"
# Bootloader
SUBSYSTEM=="usb", ATTRS{idVendor}=="1915", ATTRS{idProduct}=="0101", MODE="0664", GROUP="plugdev"
```
To connect the Crazyflie 2.0 via USB:
```
sudo touch /etc/udev/rules.d/99-crazyradio.rules
```
```
# Crazyflie 2.0
SUBSYSTEM=="usb", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="5740", MODE="0664", GROUP="plugdev"
```
Reload udev rules:
```
sudo udevadm control --reload-rules
sudo udevadm trigger
```
## Previous project
On Ubuntu 18.04 with ROS Melodic, [crazyflie_ros](https://github.com/whoenig/crazyflie_ros) works perfectly. It has an RViz interface (not too important now). To run it:
```
roslaunch crazyflie_demo teleop_ps3.launch uri:=radio://0/80/2M joy_dev:=/dev/input/js2
```
