# Scripts

Auxiliary files that are not part of any ROS 2 package: data post-processing (`ros2 bag` to `.csv` conversion, plotting) and Matlab/Simulink models/identification.

## Python (`Python/`)

- **`bag2csv.py`**: converts every topic in a `ros2 bag` to a `.csv` file, one per topic, based on the message type (no need to know topic names ahead of time). Usage: `python3 bag2csv.py <bag_folder>`.
- **`plot_csv.py`**: plots the `.csv` files generated by the two scripts above with matplotlib, one figure per file. Usage: `python3 plot_csv.py file1.csv [file2.csv ...]`.
- `basiclog.py`, `motion_cmd_test.py`, `motion_test.py`: **pending manual review** (see `AUDIT.md` on the `doc` branch) — untouched in this pass, decide whether they're still useful.

## Matlab (`Matlab/`)

- **`plot_csv.m`**: Matlab equivalent of `plot_csv.py`, reads `bag2csv.py`'s `.csv` files directly with `readtable`. Usage: `plot_csv('file1.csv', 'file2.csv')`. **Not verified in this environment** (no Matlab available in this session's sandbox) — review before relying on it.
- `Crazyflie_Graphs.m`: existing plotting script, but it does **not** read `bag2csv.py`'s `.csv` files — it expects variables already loaded in the workspace (`references`, `dron_state`, `altitude_controller`, ...) produced by the `Crazyflie_Launch.m` + `bag2txt_sim.sh` + `Txt2Mat.m` pipeline. Left untouched rather than adapted, to avoid breaking that existing pipeline.
- `Crazyflie_Launch.m`, `Crazyflie_Model.m`, `Crazyflie_Stats.m`, `Crazyflie_IAE.m`, `ROS_Controller_Example.m`, `ROS_test.m`, `ROS.slx`, and the contents of `Controladores/`/`Modelos/`: **pending manual review** (see `AUDIT.md` on the `doc` branch) — untouched in this pass, decide which are still useful and remove the rest.
